# YouTube Playlist Manager

Uses the YouTube API to edit your YouTube playlists. Especially for those with large, bulky playlists.

<br>

**Requirements:**
- [Python](https://www.python.org/downloads/) (Version 3.10 or higher)

<h2> How to Install </h2>

1. **Create Python virtual environment:**

```shell
python3 -m venv path/to/venv_name
```

2. **Activate virtual environment**

    - Linux: `. path/to/venv_name/bin/activate`
    - macOS/Linux: `source path/to/venv_name/bin/activate`
    - Windows (PowerShell): `. .\path\to\venv_name\Scripts\activate`
    - Windows (Command Prompt): `path\to\venv_name\Scripts\activate`

   *Notes*

   - If successful, command line will display name of virtual environment: `(venv_name) $ `

   - To close a virtual environment, simply type `$ deactivate` in the terminal

3. **Clone repository**

```shell
git clone https://github.com/s0phL/ost-video-creator.git
```

4. **Navigate to project directory**

```shell
cd path/to/ost-vid-creator/
```

5. **Install dependencies**

```shell
pip install -r requirements.txt
```

<h2> How To Use </h2>

```shell
python playlist_manager.py
```
- Once the program is running, input the number corresponding to the displayed command (will be printed)
- To exit the program, enter ``q`` on home screen or ``ctrl c`` anywhere

**Insertion Only**

```shell
python playlist_manager_basic.py
```

- To exit the program, ``enter`` out or ``ctrl c`` anywhere
